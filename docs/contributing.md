# Contributing

Change a sample inside `apps/<project>/<variant>/`. Keep the host and the consumer next to the README that explains how to run them.

When you add or rename a scenario, update:

- `apps/<project>/README.md`
- the scenario README, in the section order from [adding-reference-app.md](adding-reference-app.md)
- the catalog table in the repository root `README.md`

See [architecture.md](architecture.md) for the folder rule: original project, then variant, then service.
